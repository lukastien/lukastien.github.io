01 — PROJECT OVERVIEW

The project

Markets don't move randomly day to day in a completely memoryless way — but how much structure is there in simple up/down/flat regimes? This project builds a discrete-time Markov chain over daily market states to find out: estimate transition probabilities from real price history, solve for the long-run regime mix, and simulate future state paths.

It is an applied companion to probability coursework (STAT 150 concepts): MLE transition estimation, stationary distributions via eigenvectors, Chapman–Kolmogorov n-step probabilities, and Monte-Carlo simulation of the fitted chain.

Implementation: a single documented Python script (markov_regime.py) using yfinance, NumPy, matplotlib, and seaborn. Data: daily SPY prices from 2015-01-01 onward, classified at a ±0.5% daily-return threshold.

State definition

r > +0.5% → Up, r < −0.5% → Down, otherwise Flat. The threshold is a parameter — changing it changes the regime story, which is itself a modelling lesson.

Estimation

Maximum-likelihood transition matrix: count observed state-to-state transitions and normalise each row into probabilities.

Long-run behaviour

The stationary distribution is the eigenvector of PT at eigenvalue 1, normalised to sum to 1 — the market’s long-run regime mix if the chain’s dynamics held indefinitely.

04 — CHALLENGES, ASSUMPTIONS & LIMITATIONS

Assumptions & limitations

The Markov assumption is strong

Challenge: Real markets have memory beyond yesterday's regime — volatility clustering, news, and trends violate first-order memorylessness.

Decision: Treat the chain as a descriptive baseline and teaching tool; the repo README makes no predictive or trading claim.

Threshold sensitivity

Challenge: The ±0.5% cut defines what counts as a 'regime', so results are conditional on that choice.

Decision: Expose the threshold as a parameter and list regime-comparison across thresholds/tickers as an explicit extension.

Stationarity is assumed, not tested

Challenge: A single transition matrix for 2015–present averages over bull, bear, and crisis periods.

Decision: Natural next steps: per-period matrices, n-step probabilities via matrix powers, and expected return times (1/π) — all listed as extensions in the repo.
